Privacy

Last updated: September 13, 2026

AIRI (AI Request Intelligence) is built to need as little of your data as possible — most of what it does requires none at all. This page explains, plainly, what's collected across each part of the app and why.

The default flavor — nothing is stored

/analyze, /project, and /report (plus its HTML/PDF variants) are fully stateless: whatever you submit — a prompt, a set of request archetypes, a batch of load-test records — is processed in memory to compute an estimate or a report, and then discarded. None of it is written to a database or logged anywhere. This covers the single-request check, traffic projection, and load-test reporting sections of the try-it page.

Exact mode — email sign-in

Switching to Exact mode and signing in involves a small amount of account-like data:

WhatWhyRetention
Your email addressTo send you a one-time sign-in code and recognize returning sign-insKept until deletion is requested (see "Contact" below)
The 6-digit codeSign-in verificationStored only as a salted hash, never in plain text; expires in 10 minutes and is single-use; periodically purged
Your session tokenKeeps you signed inA signed token kept in your browser's local storage — never stored server-side; expires after 30 days

There's no password to set, no profile to fill in, and no marketing use of your email — it exists solely to run the sign-in flow.

Exact mode — your own API key (BYOK)

When this deployment asks you to bring your own Anthropic/Google API key for Exact mode, that key is stored only in your own browser's local storage. It's sent along with each Exact request so AIRI can call that provider on your behalf, and is never written to AIRI's database, logged, or shared. You can clear it at any time from the "Manage keys" option once signed in.

What we send to other services

Running AIRI relies on a small number of other services, each only for the specific job below:

ServiceWhat it sees
Neon (Postgres)Email addresses, hashed sign-in codes, and this deployment's admin-configured settings
ResendThe email address and 6-digit code needed to deliver a sign-in email
Anthropic / GoogleThe prompt or messages you're checking — only for the specific Exact-mode request you make, only to their free token-counting endpoints, and only when Exact mode is in use
Render / GitHub PagesStandard web hosting logs (e.g. IP address, request timing) for the API and static site respectively — nothing AIRI-specific

Cookies & tracking

AIRI doesn't use tracking cookies, third-party analytics, or advertising of any kind. The only browser storage involved is your session token and, in BYOK mode, your own API key(s) — both kept locally in your browser, both under your control to clear at any time.

The author profile

The Author page shows a profile the site admin has chosen to make public (name, photo, bio, links) — it's not information collected from visitors, and visiting that page doesn't share anything about you with us.

Children's privacy

AIRI is a developer tool and isn't directed at children; we don't knowingly collect data from anyone under 13.

Changes to this page

If what AIRI collects changes — a new feature, a new integration — this page is updated to match, with the date above reflecting the latest revision.

Contact
