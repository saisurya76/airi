Developers

Everything on the try-it page is also a plain HTTP API, and the core estimation logic is also available as a compiled library if you'd rather run it in-process. This page is for wiring AIRI into your own app.

Get the compiled library

AIRI's source isn't publicly distributed. What you can download here is a compiled build of just the core estimation library — the token/cost math behind analyze()/project()/build_report() — as bytecode only, no .py source included. It doesn't contain the API server, the frontend, SQL migrations, or docs; for everything else, use the HTTP API below instead of self-hosting.

Generated fresh from what's currently deployed — always matches the live service.

Using the compiled library

Once unzipped, drop the airi/ folder next to your script (or add it to PYTHONPATH):

from airi import analyze

result = analyze(prompt="Explain quantum computing simply.",
                  model="gpt-4o", expected_output_tokens=500)
print(result.to_dict())

One requirement worth knowing up front: this is compiled bytecode, tied to the exact CPython minor version that produced it (currently Python 3.11.x — see the README.txt in the download for the exact version at any given time). Importing it under a different Python 3 minor version raises a "bad magic number" error rather than silently misbehaving. If that's a blocker, the HTTP API below works from any language, no Python version to match at all.

API at a glance

The core endpoints — this is the easiest integration path if you don't need to run the estimation math in-process:

EndpointWhat it does
POST /analyzeToken/cost/context estimate for one request
POST /analyze/exactSame, using the real provider token-counting API (signed-in)
POST /projectVolume projection across several request types
POST /reportConsolidate a load test's /analyze results into a report
POST /report/pdfSame report, rendered as a downloadable PDF
GET /modelsSupported models + pricing/context-window metadata
