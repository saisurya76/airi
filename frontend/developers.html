Everything on the try-it page is also a plain HTTP API, and the estimation logic itself is an importable Python library with zero mandatory network calls. This page is for wiring AIRI into your own app.

Running it yourself

Once unzipped:

pip install -r requirements.txt
uvicorn api:app --reload

That's enough for /analyze, /project, and /report* — no database, no API keys, no config. Email sign-in and Exact mode (real Claude/Gemini token counts) are opt-in and need a bit of setup; see docs/EXACT_MODE.md and docs/ADMIN.md in the download.

API at a glance

Full request/response reference is in docs/API.md (in the download above). The core endpoints:

EndpointWhat it does
POST /analyzeToken/cost/context estimate for one request
POST /analyze/exactSame, using the real provider token-counting API (signed-in)
POST /projectVolume projection across several request types
POST /reportConsolidate a load test's /analyze results into a report
POST /report/pdfSame report, rendered as a downloadable PDF
GET /modelsSupported models + pricing/context-window metadata
