Workspaces

Organize your projects into workspaces, invite your team, and (soon) run every AIRI tool per project with a shared dashboard. Sign in with a one-time email code to continue — the same sign-in used for Exact mode on the main page.

Your app key

A 4-digit PIN you choose. AIRI asks you to re-enter it before any delete (a workspace, a project, a team member) — a confirmation step, not a login credential. Only a hash of it is ever stored.
