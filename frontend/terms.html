What AIRI is

AIRI estimates tokens, context usage, and cost for a request to an AI model, before or instead of sending it. Standard-flavor estimates use published tokenizer/pricing data and are approximations, not a guarantee of what a provider will actually charge or count — Exact mode narrows that gap by calling the provider's own token-counting API for the models that support it, but even then, final billing is always between you and that provider. Don't rely on AIRI as your sole source of truth for a cost-sensitive decision.

Accounts, sign-in, and access codes

Exact mode and Workspaces need a signed-in session: either the account owner's one-time email code, or — for an invited team member — a persistent access code issued by that workspace's admin. A few things follow from that:

  • You're responsible for keeping your access code (and your email inbox, for the OTP flow) to yourself — anyone with either can sign in as you.
  • A workspace's admin is whoever created it; they can add, disable, re-enable, or remove members, and can regenerate a member's code at any time — doing so immediately invalidates the old one.
  • If you're a team member, your access to a workspace can be disabled or removed by that workspace's admin at any time, at their discretion — that's a normal part of how the feature works, not something AIRI mediates.
  • Don't share a code with someone the admin didn't intend to have access, and let the admin know if you think a code has leaked.
